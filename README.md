# GameHall

GameHall is a private, offline Windows application for running game nights, tables, players, events, and leagues. No account, browser, server, Node.js, or command line is required.

[**Download GameHall for Windows**](https://github.com/TemuulenMunhkjargal/GameManager/releases/latest/download/GameHall-Setup.exe)

## Install

1. Download `GameHall-Setup.exe` using the button above.
2. Open the downloaded installer.
3. Complete the short setup, then launch GameHall from the Start menu or desktop shortcut.

GameHall stores its database and backups locally on your computer. It does not require an internet connection for normal use.

> Windows may show a Microsoft Defender SmartScreen warning while GameHall is not code-signed. If you downloaded it from this official repository, select **More info**, then **Run anyway**. A trusted code-signing certificate is the remaining step needed to remove that warning.

## What GameHall includes

- Table occupancy, seating, guests, and play-time tracking
- Player directory and membership management
- Events, calendar views, and archived event history
- Flexible league formats, standings, participants, and winners
- Discord announcements through an optional webhook
- Automatic local backups and restore tools
- Default green, light, and dark themes

## Requirements

- Windows 10 or Windows 11 (64-bit)
- About 500 MB of free disk space
